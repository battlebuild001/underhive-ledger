네크로문다 룰 데이터 보완·검증 보고서
확인일: 2026-10-15 (한국 시간)

1. 적용 기준
- 제공 번역 합본은 공식 2026 신판 소개의 능력치·행동·전후 절차와 일치하여 N26 Necromunda: Skirmish 자료로 판정했다.
- 같은 판본과 대상 범위에서 2026-09-04 공식 FAQ/Errata를 인쇄본·번역보다 우선했다.
- 원서 표 이미지가 명확한 경우 번역·전사 메모보다 우선했다.
- 카탈로그를 내려받은 날짜는 규칙 발행일로 취급하지 않았다.
- N23 기록 17,430개는 기존 값과 관계를 그대로 보존했다.
- 공식 PDF 원문 대조는 사용자가 생략을 요청했다.

2. 반영 범위
- 기존 카탈로그 406개 항목 보완 + 기본 규칙·무기 특성 151개 신규 항목 = 557개 데이터 항목.
- 무기 프로필 85행 전부 대조, 장비 105항목에 관련 설명·출처 연결.
- 스킬 45, 스킬군 8, 파이터 하위유형 22, 효과 44, 부상 복사본 17.
- 기본 영토 19, 시나리오 표 항목 24, 부업 복사본 6, 기본 전술 18, 기본 캠페인·성과 보완.
- 무기 특성 46, 기본·전투·전후 절차 규칙 105.
- 상위·중첩 무기 프로필, 시나리오 항목, 전술 카드의 정확한 ID 복사본 동기화.
- 제공 자료에 없는 추가 갱·장비·스킬·영토의 설명은 지어내지 않았다.

3. 교정한 사항
- Autopistol 워프 탄환: 단거리 6인치 → 4인치. 제공 합본의 영어 원서 표(image22)를 직접 재확인했다.
- N26 승급: I/Ld/Cl/Wil/Int는 +1, WS/BS/Sv는 목표값 -1. 기존 혼합 판본 계산을 바로잡았다.
- N26 Any skill (12): Wyrd/Psychoteric 접근권과 명시적인 Fighter-only 자격을 선택창·저장 시 다시 검사한다.
- Quickening: 최신 공식 정오표에 따라 Single 행동.
- Rapid Fire: Ammo 검사 실패는 탄약 기호 1개 추가이며 화력 주사위 추가가 아니다.
- Mounted 전진·회전, Drop rig/Grapnel의 Mounted 제한 등 최신 정정을 설명과 구조 데이터에 반영했다.
- 카탈로그 영토 설명이 실제 캠페인에 표시되지 않던 연결을 수정했다. 사용자 설명·명시적 삭제는 우선한다.
- rig-glitches의 장비 ID에 들어간 문자열 undefined 16곳은 null로 정규화했다. 없는 장비를 추정 연결하지 않았다.

4. 정상임을 확인해 유지한 대표 값
- Trazior heavy stubber Rapid Fire는 3. 이전 이미지 전사 메모의 1을 오류로 판정했다.
- Redemptionist Deacon 100cr, Shock lance 명칭, Exclusive 장비, Arachni-Rig 하위유형·옵션, Ironhead seismic grenade 장거리 24인치 등 이미 반영된 정오표는 수정 건수로 중복 집계하지 않았다.
- 눈·손 부상의 BS/WS +1은 목표값 악화이므로 정상이다.
- 기존 Wealth 후처리는 보관 장비 가치를 이미 포함하므로 잘못된 중복 수정은 하지 않았다.

5. 근거 부족·번역 충돌의 처리
- Trazior heavy stubber 가격: 카탈로그 85 / 번역 본문 80. 원서 가격표와 날짜가 있는 정정이 없어 85 유지.
- Sprint 괄호 범위, 전문화 7행/공식 8개 차이, D3 내림 문구, TP 산식, 성장표 결과 선택 방향 등은 모호성을 별도 기록하고 자동 수식을 확정하지 않았다.
- 소스 검토 기록에는 같은 문제를 여러 규칙에서 인용한 중복도 포함한다. 기록 개수는 서로 다른 앱 오류 수가 아니다.
- 기존 저장된 승급 이력은 수동 수정·임포트와 구별할 수 없어 일괄 재작성하지 않았다.

6. 검증
- 전체 32개 테스트 묶음 통과. 승급의 두 판본 특성 저장/되돌림, Wyrd 선택·저장 제한, 설명·모달·모바일 포커스, N23 값 보존을 포함한다.
- 무효 참조 정리 후 데이터 재검증과 파이터 관련 검사를 추가 수행했다.
- JSON과 브라우저 스크립트 일치, 재적용의 멱등성, 출처 유효성, 18개 초상화의 실제 Worker 응답·DB 저장 빌드 검증을 통과했다.
- 관리 환경에 지원되는 브라우저 QA 도구가 없어 실제 브라우저 화면 검사는 수행하지 않았다. DOM 상호작용과 Worker 검증을 사용했다.
- 전체 36,287행·관계 참조 78,746개를 검사했다. 판본 비교 76,353개와 중첩 복사본 1,877개는 모두 일치했다. 신규 결손·중복 ID·복사본 불일치 0.
- 기존 참조 16곳을 정리했으며, 남은 29곳은 모두 N23의 장비 참조다. 제공 신판 자료로 대상을 확정할 수 없어 임의 연결하지 않고 정확한 목록을 data/catalog-integrity-audit.json에 수록했다.
