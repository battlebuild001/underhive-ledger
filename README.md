# 언더하이브 장부

네크로문다 갱과 캠페인을 관리하는 독립 제작 팬 앱입니다.

## 기능

- 갱, 파이터, 능력치, 장비, 효과, 부상, 경험치, 스킬, 자원, 창고, 활동 기록
- 차량, 장비, 지속 손상, 전술 카드, 갱 복제, 파이터 복제, 인쇄용 명단
- 캠페인 참가자와 역할, 영토, 지도 위치, 전투 기록, 노트, 하우스 룰, 성과
- 현재 브라우저 저장, JSON 백업과 복원

## 범위

공개 Munda Manager 안내와 소스 구조를 참고해 새로 구현했습니다. 원본 앱의 비공개 데이터와 규칙 데이터베이스는 포함하지 않습니다. 브라우저 저장 방식이므로 계정 간 동기화, 친구, 알림, Discord 연결, 실시간 협업, 공개 REST API는 제공하지 않습니다.
