# 언더하이브 장부

네크로문다 갱과 캠페인을 관리하는 독립 제작 팬 앱입니다.

## 기능

- 갱, 파이터, 능력치, 장비, 효과, 부상, 경험치, 스킬, 자원, 창고, 활동 기록
- 차량, 장비, 지속 손상, 전술 카드, 갱 복제, 파이터 복제, 인쇄용 명단
- 캠페인 참가자와 역할, 영토, 지도 위치, 전투 기록, 노트, 하우스 룰, 성과
- 현재 브라우저 저장, JSON 백업과 복원

## 범위

공개 Munda Manager 안내와 소스 구조를 참고해 새로 구현했습니다. 원본 앱의 비공개 데이터와 규칙 데이터베이스는 포함하지 않습니다. 브라우저 저장 방식이므로 계정 간 동기화, 친구, 알림, Discord 연결, 실시간 협업, 공개 REST API는 제공하지 않습니다.

## 로그인 후 화면 조사

제공된 계정으로 홈, 계정, 갱, 파이터, 캠페인, 인쇄 화면 등 21개 경로와 주요 탭을 확인했습니다. 사용자 정의 항목에는 장비, 파이터 유형, 스킬·세트, 갱 유형, 거래소, 컬렉션이 있습니다. 전투 화면에는 활성 세션과 완료된 전투 기록이 별도로 있습니다. 개인 계정 데이터와 인증 정보는 이 저장소에 넣지 않았습니다.

확인한 화면을 토대로 사용자 자산, 장비 프리셋, 파이터 유형 프리셋, 전투 세션, 캠페인 팩을 추가했습니다. 원본의 규칙 엔진과 규칙 데이터, 서버 계정 기능은 아직 구현되지 않았습니다.

## 추가한 게임 진행 기능

파이터의 경험치 사유와 발전·지속 부상·로드아웃, 갱의 거래소 구매·사이클 정산·주사위, 캠페인의 순위·포로·자원·전투 보고, N23/N26 목록 필터와 캠페인 JSON/XML 다운로드를 지원합니다. 비용과 효과는 플레이어가 입력하며 공식 규칙의 자동 판정은 제공하지 않습니다.
